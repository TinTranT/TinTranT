# 🛠️ Personal Tools

Small Chrome extensions (Manifest V3) I built for my own daily workflow. [← Back to profile](README.md)

## 📜 AutoScroller

Scrolls web pages for you, hands-free. [GitHub Repo](https://github.com/TinTranT/AutoScroller)

## 🔧 URL Param Editor

View and edit a tab's URL — query params, hash params, protocol/host/port/path — before applying the change. [GitHub Repo](https://github.com/TinTranT/URL-Param-Editor)

## 🛡️ VirusTotal URL Scanner

Scans the URLs you visit against VirusTotal's threat intelligence database. [GitHub Repo](https://github.com/TinTranT/VirusTotal-URL-Scanner)
